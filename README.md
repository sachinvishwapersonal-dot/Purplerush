# BlooRush: Purplerush Automated Cleaning Platform

A modern, fully automated operations dispatch and field workforce management platform for **BlooRush** (`bloorush.in`).

## 🌐 Live Demos & Architecture
- **Customer Booking**: `customer.html` — Dynamic multi-tier service catalog with direct automated ingestion.
- **Live Order Tracking**: `track.html` — Visual progress stepper, real-time stopwatch & 5-star rating.
- **Field Partner PWA**: `partner.html` — Multilingual mobile cleaner app (EN/HI/MR) with GPS navigation and live service timer.
- **Operations Hub**: `admin.html` — Live revenue KPIs, WhatsApp notification feed & attendance roster.
